# Pages — dependency trees

Traced from each entry through local imports (`@/`, `./`, `../`), four
levels deep, first 40 per page. This is the **candidate set** for
`--context-file`, not an include-everything list — apply the payload
budget. Line counts are given so the budget can be summed before a call.

**Warning for this repo:** `src/lib/calendar/models.ts` is 1024 lines and
`src/lib/store/calendar.ts` is 1082 — both are pure logic/types and should
never be passed as design context. `globals.css` is 1686; pass the token
summary at the top of `theme.md` instead.
