# Shifter — макет интерфейса

Отдельный проект: только интерфейс, без логики. Ни одного запроса, ни одного
обработчика — кнопки не нажимаются, поля не вводятся. Данные выдуманы и лежат
в `src/mock/data.ts`.

```
npm install
npm run dev      # http://localhost:5300
```

Разделы:

- `/` — зачем этот вид такой
- `/foundations` — цвет, шрифт, все примитивы
- `/screens` — календарь, смены, места, график, подработки, выплаты, банк, год
- `/modals` — окна и панели
- `/phone` — те же экраны шириной в ладонь

Язык называется «Ночная смена»: тёплая темнота вместо белого дашборда,
один латунный акцент, чек с раздачи как опорный объект. Приложением
пользуются в два часа ночи после закрытия — отсюда всё остальное.
